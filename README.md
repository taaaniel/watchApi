# WatchAppApi

WatchAppApi is a backend API project designed for a frontend web application and a mobile application.

This project was created mainly for learning purposes. It is a simple example of how to build an ASP.NET Core Web API that can provide data to client applications.

Even though it is a learning project, the solution can also be used as a starting point for real applications or extended for personal and commercial use.

## Purpose

- Provide a simple API for managing watch-related data.
- Serve as a backend for web and mobile clients.
- Help practice ASP.NET Core, REST API design, and project structure.

## Current Features

- Get all watches
- Get a watch by ID
- Swagger UI for API testing
- Sample JSON data source

## Technology

- ASP.NET Core Web API
- .NET 9
- Swagger / OpenAPI

## Notes

This repository is intended as a learning and experimentation project, but the general approach and structure can be reused in other solutions.
